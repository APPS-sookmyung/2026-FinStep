## Vercel + Neon 배포

React와 FastAPI를 Vercel의 같은 주소에서 제공하고 Neon PostgreSQL에 로그인·진단 결과·시뮬레이션 진행 상태를 저장합니다.
설정은 `vercel.json`, 배포 절차와 환경 변수는 [배포 안내](docs/vercel-deployment.md)를 참고하세요.

## 학교 AI Gateway

기본 AI 연결은 학교 BAZE Gateway의 Gemini 3.8 Flash입니다. 필요한 환경변수와 연결 확인 명령은 [학교 Gateway 설정](docs/school-gateway.md)을 참고하세요.
